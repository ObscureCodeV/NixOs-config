# NixOs-config
Personal NixOS config for pet projects &amp; home lab

## Features
- Nix Flakes for deterministic builds
- Hyprland (Wayland compositor)
- Firejail sandboxing for browsers/messengers
- Btrfs + zstd compression (SSD optimization)
- Encrypted backups (tar + age) to local/Google Drive
